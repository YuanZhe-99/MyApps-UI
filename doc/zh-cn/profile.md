# 资料与头像

`myapps_profile` 负责资料模型、字段合并、串行更新、头像图片处理、圆形显示和
编辑器。依赖 Flutter、image、path 和 uuid，不依赖 Riverpod、路由、同步引擎或
平台图片选择器。

## 应用边界

`ProfileRepository` 接收当前存储目录、原子 JSON 写入及保存通知。
图片解析和删除回调保留应用图片服务的行为。应用保留静态 ProfileStore 包装、
选择器、Riverpod 状态、数据模块注册及本地化资料对话框。公共头像显示接收文件解析器，
编辑器接收明确的本地化标签。公共资料标题组件接收头像、姓名、文案和编辑回调。

## 兼容性

`profile.json` 仍使用版本 1，姓名和头像分别拥有 UTC 时间戳。同时间戳保留本地值，
带时间戳的 null 删除可同步。读取、合并及写入保留未知字段。本地保存和合并生成的
格式化 JSON 字节一致。损坏资料可显示空占位，但更新不会覆盖损坏文件。
每次头像保存使用新的 `images/avatar_<uuid>.jpg`，512 像素正方形、JPEG 质量 88。
只在本机删除替换的头像，远程垃圾清理行为不变。
各应用资料仍独立，共享实现不共享身份。

## 验证

公共包测试覆盖旧 JSON、逐字段合并、串行更新、损坏文件保护、图片处理、图片延迟
到达，以及编辑取消和错误。应用资料、同步、恢复及组件测试验证适配和模块顺序。
