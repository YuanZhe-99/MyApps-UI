# 使用方矩阵

| 使用方 | 品牌色 | 导航 | 业务布局 |
|---|---|---|---|
| MyAnime | 靛蓝 | 应用导航壳和用户位置选择 | 动画列表和统计 |
| MyDay | 靛蓝 | 应用导航壳和用户位置选择 | 待办、财务、体重、亲密关系 |
| MyDevice | 蓝色 | 应用导航壳和用户位置选择 | 设备、服务、网络、数据集 |
| MyNihongo | 樱花粉 | 应用导航壳和用户位置选择 | 学习、参考表格、练习 |
| MyTranscribe | 青绿色 | 应用导航壳和用户位置选择 | 任务、模型、转写阅读 |
| MyVidComp | 原有界面品牌色 | 原有侧栏和底栏布局 | 转换、进度、审核 |

五个主应用使用共享基础主题。MyVidComp 保留自己的 Material 3 基础定制，
使用公共 Expressive 覆盖层。0.1.0 中导航目的地、路由、角标、设置持久化和资料数据
仍由应用负责。各应用验证后在自己的版本历史中记录接入结果。
