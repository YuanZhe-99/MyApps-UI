# 组件职责

| 组件领域 | 共享职责 | 应用职责 |
|---|---|---|
| 主题 | 基础主题和 Expressive 覆盖层 | 品牌色、主题选择和定制 |
| 自适应布局 | 几何、容量和分区计算 | 内容约束和布局策略 |
| 导航 | 导航壳呈现和实际内容边界 | 目的地、路由、角标和位置持久化 |
| 设置 | 分节、分段、带标签选择及在线 API 输入控件 | 状态、持久化、平台条件和业务行 |
| 资料 | 通过适配提供资料和头像组件 | 数据、存储、入口和本地化 |
| 通用翻译 | 公共外观和导航 ARB 值 | 运行时代理和应用专用文案 |

应用可独立选用各包和组件。共享库不规定品牌、路由结构或业务布局。
实际使用情况和接入验证记录在各应用自身文档中。
