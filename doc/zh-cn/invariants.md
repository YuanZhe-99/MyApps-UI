# 行为契约

保留 `material3`、`expressive`、`bottom`、`sideOnWide` 和 `side` 枚举名称。
默认风格为 Expressive，只改变组件形状和字体表现，不改变颜色。
动态配色由调用方提供；平台是否允许动态配色由应用决定。
分屏要求宽度 >= 600、高度 >= 480、宽高比 >= 0.82。
侧栏适用条件只检查宽度是否达到 600；实际导航位置仍由应用决定。
列容量由内容宽度、每列最小宽度、间距及最大列数计算。
现有设置文件和同步格式保持兼容。

应用现有 `shellContentWidth` 仍根据宽度预测侧栏。按实际导航位置计算空间
属于下一阶段导航容器工作；本次抽取保留原有行为。
