# 设置组件与通用翻译

## 组件

`MyAppsSettingsSegmentRow` 管理图标、标题、说明布局和选择控件的 16 像素水平边距。
主题、界面风格和导航偏好使用此呈现。`MyAppsSettingsSegments` 以等宽选项撑满有界
设置栏，标签居中并允许两行。默认隐藏选中勾号，保留 Material 选中样式和语义。
当前字体比例下两行仍放不下时才使用纵向选项。应用注入值、本地化文案和
持久化回调。数据和 AI 设置呈现属于相应共享库。

`MyAppsSettingsSection` 显示标题和应用提供的设置行，标题边距可配置以适应应用间距。
`MyAppsSettingsSegments` 包装单选 Material 分段按钮，保留值、图标和
选择回调。`MyAppsSettingsChoice` 提供带标签分段或下拉控件，
支持禁用及可选帮助文字。宽度阈值和最大分段数量是明确参数，应用保留选择策略。

应用负责设置状态、存储、路由、平台条件和业务行。公共组件不依赖 Riverpod、存储
或应用模型。各组件可独立接入，应用也可保留弹窗选择器。

## 在线 API 输入

`MyAppsEndpointField` 验证端点文本具有允许的协议（默认 `https`/`http`）和主机名，
以内联方式显示调用方提供的无效提示，并通过回调报告解析得到的 `Uri`（或 null）。
调用方的 `errorText`（例如传输安全拒绝原因）优先显示。可选尾部组件显示调用方
维护的状态。`MyAppsEndpointField.parse` 提供相同的规则。

`MyAppsSecretField` 默认遮蔽，显示/隐藏切换的提示文字由调用方注入。禁用输入建议、
自动更正和输入法学习，从不记录值。已保存的密钥从不传入：`hasSavedValue` 显示遮蔽
占位符；清除操作清空已输入文本并调用 `onClear`，由应用删除已保存的值。

`MyAppsConnectionTestRow` 显示空闲、测试中（进度，按钮禁用）、成功和失败状态，
调用方提供的消息以实时区域播报。`onTest` 执行测试；组件不含网络代码。

`MyAppsPrivacyNotice` 显示图标、标题、正文、信息或警告级别及可选操作，用于数据离开
本设备等披露。所有文案由应用或使用它的共享库提供。

## 通用翻译

`l10n/common_<locale>.arb` 负责英语、简体中文、繁体中文和日语中完全一致的外观
及导航文案。这些目录合入应用 ARB 文件，不增加运行时本地化代理。
现有生成访问器和应用语言回退保持兼容。应用专用文字和有意保留的翻译差异仍在
应用目录中维护。

发布前运行 `python3 tool/common_l10n.py --check <app-root> ...`，或运行
`python3 tool/common_l10n.py --write <app-root> ...` 应用通用值。
工具写入前验证所有输入，保留其他键及元数据，并跳过应用不支持的语言。
目录变动后运行各应用的 `flutter gen-l10n`。使用方 CI 检查公共键。

## 验证

组件测试验证选择回调、禁用、帮助文字及可配置间距；在线输入测试覆盖验证、遮蔽、
占位符、清除、测试状态、提示操作和点击区域。目录测试覆盖漂移、缺少键、
不支持的语言及应用自有条目的保留。应用设置和全量回归测试验证控件仍通过原有
状态对象保存。
